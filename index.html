Large Text Uploader - Ethereum

This tool uses transaction calldata to upload large batches of text to the Ethereum blockchain

Each transaction is limited to ~500k characters. If your transaction fails, split it into parts and try again.

Render HTML

If you used the tool above to upload HTML, we can render that HTML as a webpage by inputting the transaction ID here. Session and local storage are shared, so make sure not to upload anything that stores sensitive data in those areas.
